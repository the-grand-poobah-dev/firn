# Firn

Firn is a savings app concept scaffold with plans backed by a simulated property portfolio.

> **SIMULATED:** Returns are targets, not guarantees. Capital can be lost. This is not an offer or solicitation to invest. Real deposits, payments, and identity-document processing are not enabled in this scaffold.

## Setup

1. Install Node.js 20+ and npm.
2. Copy `.env.example` to `.env.local` and fill in your own Supabase credentials. Never commit secrets.
3. Install dependencies with `npm install` (use `npm ci` once a lockfile exists).
4. Start development with `npm run dev`.
5. Validate with `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`.

Routes and backend features are placeholders at this stage.
